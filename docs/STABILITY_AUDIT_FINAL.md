## 7. 生产隔离检查

- 默认生产环境下 `isTestModeEnabled({ DEV: false })` 为 false，首页组件不渲染“测试模式”入口。
- `?testMode=1` 只表达请求，未启用时 `isTestModeRequested` 仍为 false，不能绕过开关。
- `App` 仅在 availability 已启用时进入 `TestModeScreen`；默认 `npm run build` 未设置 `VITE_ENABLE_TEST_MODE=true`。
- 测试存档执行器只接收注入的内存 `TestStorageAdapter`；故障模拟不修改 `window.localStorage`。
- 测试牌谱仅显式导出且标记 `source=test-mode`，不会自动写普通牌谱库；普通比赛默认来源仍为 `local-match`。
- 默认生产构建通过，无 TypeScript 错误；普通对局、保存与牌谱专项回归全部通过。
- 正常游戏、牌谱回放和测试模式共同使用 1280×720 逻辑画布外壳；支持尺寸不产生水平或整页垂直滚动，低于最低尺寸不会继续渲染牌桌。
